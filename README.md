# H20 多流 MoE 协同实验

验证：**专家分别读取、写回多流状态，是否能在计入通信成本后改善训练效率？**

状态：实验方案已建立；训练代码、性能数据和有效性结论尚未产生。

## 核心设计

- 保留 4 条跨层残差流；共享专家始终执行，路由专家采用 Top-2。
- 专家读取进入本层时已有的状态，不等待共享专家的本层输出。
- 状态流与专家不一一绑定；优先验证专家特定读取，再优化通信。
- 双随机混合不代表全网络稳定；包含基线不代表训练表现必然更好。
