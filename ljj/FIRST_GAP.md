# 理论到实验的第一处断点

本页只定位**初始化到第二个 MoE 入口**的第一处差异，不声称解释 1,000 步后的全部质量结果。复现代码为 `experiments/check_theory_gap.py`、`scripts/run_theory_gap.sh`；原始 H20 输出在 `evidence/h20-2026-10-27/theory-gap/`。Slurm 作业 `2943` 于 `vllm-sgp-h20-03` 完成（`COMPLETED 0:0`，`00:00:45`）；使用与 `RESULTS.md` 一样固定的 Qwen3-0.6B-Base、Transformers fork、Parquet 验证数据，FP32、batch 2、序列 128。只做前向，不重训。

## 先区分两种理论命题

根目录 README 第 3 节的 `F_B ⊆ F_C ⊆ F_D` 仅比较可表达函数集合的最优训练目标值；它从未推出相同优化预算下 D 的验证 NLL 必然更低。第 4 节的平方函数反例则另外**指定**了 `(t,-t)` 与两条非均匀、不同的读向量，证明存在一种可被 D 利用、固定平均读取会丢弃的信息。它没有证明当前 Qwen 提升后的状态分布中存在目标需要的同均值不同标签，也没有保证优化器会学到那两个读向量。

## 把反例代入实际 warm-start

在首个 MoE 入口，所有流都是同一个 `h`。五个专家从同一个 Qwen MLP 复制，输出投影都乘 `0.5`；Top-2 门控和为 1。所以在 FP32 理想算术下，共享专家与路由专家合起来仍为原 MLP `M(h)`，首个 MoE 的四流出口是

```math
X_s^+=h+b_s M(h),\quad \bar X^+=h+M(h),\quad X_s^+-\bar X^+=(b_s-1)M(h).
```

`b=(1.03,0.99,0.99,0.99)`，因此四流中心化状态只沿 `[3,-1,-1,-1]` 一个流方向。增大写回对比为 `(1.6,0.8,0.8,0.8)` 只改变该方向的幅度，没有新增独立方向。注意：README 的两流反例本身也是一维中心化状态，**一维不是失效的充分原因**。

真正的第一个零信号出现在读取端：所有 `read_weight`、`read_bias` 初始化为零，使所有专家的 `a_j=(1/4,1/4,1/4,1/4)`。于是第二个 MoE 尽管收到非零流差，所有专家仍读到同一个 `\bar X`；理论反例中的非均匀读取在实验起点并不存在。第一层读权重因输入流完全相同而梯度为零，第二层才有训练出差异的可能。

| 初始写回对比 | 首个 MoE 入口/出口流差 RMS | 出口偏离固定流方向 RMS | 首层公式最大误差 | 第二个 MoE 专家读输入最大差 | 注入非均匀读取后的读输入/专家输出 RMS 差 |
|---|---:|---:|---:|---:|---:|
| 原始 `0.01` | `0 / 0.003001` | `1.52e-8` | `1.43e-6` | `0` | `0.00416 / 0.00144` |
| 高对比 `0.20` | `0 / 0.060019` | `1.62e-8` | `1.91e-6` | `0` | `0.08317 / 0.02731` |

五个复制专家在固定输入上的最大输出差约 `1.31e-6`。未经训练时，后续层的中心化流状态也几乎仍沿同一流方向：标准写回第 27 层入口流差 RMS `0.1150`，正交 RMS `1.75e-6`；高对比对应 `2.3001` 和 `2.11e-6`。这些微小正交残差是有限精度数值结果，不声称逐位对称。

注入试验只临时将第二个 MoE 的共享/一个路由专家读偏置设为 `[0.7,0.1,0.1,0.1]` 和 `[0.1,0.3,0.3,0.3]` 的对数，随后恢复原值。专家读输入及非线性输出立即分离，说明前向路径**可以**利用这种流差；没有修改外部输入、数据或模型结构。这是理论反例的能力检查，不是训练收益实验。

## 定位与下一道门槛

第一处理论/实验差异在**可达状态与读映射的初始化**，不是 H20 kernel、Sinkhorn 范数界或 BF16：FP32 即可复现。更精确地说，状态已产生一维对比，但独立专家读映射被初始化在共享均匀子空间，使该对比暂时没有进入专家；理论例子预先跳过了这一步。原有 1,000 步实验后来确实学到非零、不同的读取参数，增大流对比也使第二个 MoE 首步读取梯度增大约 19 倍，却仍未见稳定验证收益（见 `MECHANISM.md`）。所以这个第一断点**不是**最终负结果的充分解释。

下一步应在固定 checkpoint 和相同 token 上检验：训练/验证损失沿有效流差读取方向是否有一致的下降梯度，再区分“数据不需要该信息”与“有用梯度存在但优化或精度没有兑现”。在此之前，不应把函数包含关系表述成实验应有收益。
